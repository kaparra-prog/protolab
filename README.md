# ProtoLab - Asistente de Laboratorio de Circuitos

ProtoLab es una aplicación web rápida, ligera y diseñada para celulares y computadores, pensada para estudiantes de primeros semestres de ingeniería electrónica, mecatrónica y afines.

## Características
1. **Circuitos Básicos:** Lista de materiales y esquemas de conexión para protoboard.
2. **Calculadora Express:** Cálculo de resistencias de LED con código de colores, divisor de tensión y amplificador no inversor.
3. **Buscador de Pinouts:** Consulta rápida de pines y voltajes de operación de circuitos integrados esenciales (LM741, 555, LM358, etc.).
4. **Checklist de Seguridad:** Reglas de oro y verificación pre-energizado para no quemar componentes en el laboratorio.

Desarrollado para funcionar sin servidor, sin bases de datos y directamente en el navegador del celular.
